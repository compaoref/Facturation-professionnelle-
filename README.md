# Facturation-professionnelle-
FacturaPro est un logiciel de gestion commerciale complet qui fonctionne directement dans votre navigateur, sans installation ni connexion internet. Créez et imprimez vos factures et bons de livraison en quelques clics, gérez vos clients, suivez vos encaissements et générez vos rapports TVA.
Fonctionnalités :
Création de factures et bons de livraison avec aperçu impression
Gestion des clients avec historique complet
Suivi des règlements et paiements partiels
Rapport TVA avec filtres par période
Paramétrage complet : taxes, retenues, numérotation, signatures, devise
Export CSV et sauvegarde JSON
Thème clair/sombre
Vos données restent sur votre appareil — aucun serveur, aucun abonnement
Téléchargez le fichier HTML, ouvrez-le dans votre navigateur et commencez à facturer.
